📖 About This Tool

What is it?

Number Converter is a tool that converts numbers between different number systems — Decimal, Binary, Hexadecimal, and Octal — instantly.

How does it work?

Each number system uses a different base:

  • Decimal (10): Uses digits 0–9
  • Binary (2): Uses digits 0 and 1
  • Hexadecimal (16): Uses 0–9 and A–F
  • Octal (8): Uses digits 0–7

The tool reads your number in the selected base and converts it to all other bases.

How to use?

  1. Select the input base (Decimal, Binary, Hex, or Octal)
  2. Type your number in the input box
  3. All outputs update instantly
  4. Click the copy icon to copy any value

Examples

  • Decimal 255 → Binary 11111111
  • Binary 11111111 → Decimal 255
  • Decimal 255 → Hex FF
  • Hex FF → Octal 377
