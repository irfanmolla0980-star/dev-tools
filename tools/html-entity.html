📖 About This Tool

What is it?

HTML Entity Encoder/Decoder converts special characters into HTML entities (like < → &lt;) and back.

Why is it needed?

  • XSS Protection — Prevent script injection from user input
  • Display code — Show <div> as text, not tag
  • Special characters — Show ©, ®, ™, →, ♥
  • Email templates — Safe HTML rendering
  • Blog/Forums — Display user comments safely

Common Entities

  • &lt; → <
  • &gt; → >
  • &amp; → &
  • &quot; → "
  • &#39; → '
  • &nbsp; → non-breaking space
  • &copy; → ©
  • &reg; → ®
  • &trade; → ™
  • &euro; → €

XSS Attack Prevention

If a user submits:

<script>alert('hacked')</script>

After encoding, it becomes safe text — the browser shows it as-is instead of running the script.

How to use?

  1. Pick mode — Encode or Decode
  2. Type or paste text
  3. Choose options if needed
  4. See output instantly
  5. Click a quick entity to insert
  6. Copy or download result

Tips

  • Always encode user input before showing in HTML
  • Use numeric entities for emoji compatibility
  • &amp; must be encoded first in any HTML output
  • Use &nbsp; to prevent line breaks
