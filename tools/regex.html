📖 About This Tool

What is it?

Regex Tester is a tool that lets you test regular expressions against sample text in real time. It highlights matches and shows detailed group information.

What is a Regex?

A regular expression (regex) is a pattern used to search, match, or replace text. Regex is used everywhere — validation, parsing, search-and-replace.

Example: \d+ matches one or more digits.

Common Patterns

  • \d — any digit (0–9)
  • \w — any word character (a–z, A–Z, 0–9, _)
  • \s — any whitespace
  • . — any character except newline
  • + — one or more
  • * — zero or more
  • ? — zero or one
  • [abc] — any of a, b, c
  • (abc) — capture group
  • ^ and $ — start / end of line

Flags

  • g — global (find all matches)
  • i — ignore case
  • m — multiline (^ and $ match line by line)
  • s — dot all (. matches newlines)
  • u — unicode support
  • y — sticky (matches from lastIndex)

How to use?

  1. Type your regex pattern in the pattern field
  2. Add flags (like g, i, m)
  3. Paste or type your test text
  4. Matches are highlighted live
  5. Click Match Details to see each match and its groups
  6. Use Quick Patterns for common regexes

Examples

  • \d+ on "abc 123 xyz 456" → matches 123 and 456
  • [A-Z]\w+ on "Hello world" → matches Hello
  • (\w+)@(\w+\.\w+) on "user@site.com" → groups: user, site.com

Tips

  • Use g flag to find all matches, not just the first
  • Escape special characters with \ (like \. for a literal dot)
  • Use (?:...) for non-capturing groups
  • Test regexes on real data before using them in code
