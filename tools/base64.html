📖 About This Tool

What is it?

Base64 Encode / Decode is a tool that converts text into Base64 format and back. Base64 is a way of representing binary data using only readable characters.

What is Base64?

Base64 is an encoding scheme that uses 64 characters to represent data:

  • A–Z (26 uppercase letters)
  • a–z (26 lowercase letters)
  • 0–9 (10 digits)
  • + and / (2 symbols)
  • = (padding, when needed)

How does it work?

Base64 takes every 3 bytes (24 bits) of data and splits them into 4 groups of 6 bits each. Each 6-bit group maps to one Base64 character.

  • Hello → SGVsbG8=
  • Hi → SGk=
  • ABC → QUJD

The = sign is padding to make the length a multiple of 4.

How to use?

  1. Pick a mode — Encode or Decode
  2. Type your text or Base64 string
  3. Output appears instantly
  4. Click Copy to copy the output
  5. Use Swap to switch input ↔ output
  6. Click Details to see the breakdown

Examples

  • Hello → SGVsbG8=
  • Hi → SGk=
  • Dev Tools → RGV2IFRvb2xz
  • SGVsbG8= → Hello

Tips

  • Base64 is not encryption — it's just encoding
  • Encoded text is about 33% larger than original
  • Padding = may appear at the end (1 or 2 times)
  • Useful for embedding images and files in text
