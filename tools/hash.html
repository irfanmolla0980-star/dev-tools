📖 About This Tool

What is it?

Hash Generator converts any text into a fixed-length string of characters called a hash. The same input always produces the same hash.

What is a Hash?

A hash is a one-way function. It takes input and produces a unique output — but you cannot reverse it back to the original text.

Hashes are used for:

  • Storing passwords securely
  • Verifying file integrity
  • Digital signatures
  • Blockchain and crypto

How does it work?

Each algorithm processes your text through a mathematical formula and produces a hash of a fixed length:

  • MD5: 128-bit (32 hex chars)
  • SHA-1: 160-bit (40 hex chars)
  • SHA-224: 224-bit (56 hex chars)
  • SHA-256: 256-bit (64 hex chars)
  • SHA-384: 384-bit (96 hex chars)
  • SHA-512: 512-bit (128 hex chars)
  • CRC32: 32-bit (8 hex chars)

How to use?

  1. Type your text in the input box
  2. All hashes appear instantly
  3. Click any ⧉ icon to copy that hash
  4. Click Details to see input size and hash lengths

Examples

  • hello → MD5: 5d41402abc4b2a76b9719d911017c592
  • hello → SHA-256: 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
  • Hello (capital H) → completely different hash

Tips

  • Even one character change → totally different hash
  • MD5 and SHA-1 are now considered weak for passwords
  • Use SHA-256 or SHA-512 for security
  • Hashing is not the same as encryption
