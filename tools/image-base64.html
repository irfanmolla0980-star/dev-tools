📖 About This Tool

What is it?

Image → Base64 converts images into Base64 text that can be embedded directly in HTML, CSS, JSON, or APIs. It also works in reverse — Base64 back to an image.

What is Base64?

Base64 is a way of encoding binary data (like images) into plain text using 64 characters: A–Z, a–z, 0–9, +, /.

This makes it safe to put images inside HTML, CSS, JSON, or email.

Why use it?

  • Fewer HTTP requests — image travels with HTML/CSS
  • APIs — send images as JSON text
  • Email — images show inside the message
  • Single-file apps — everything in one HTML file
  • Offline apps — no external files needed

Copy Formats

  • Raw — plain Base64 string
  • Data URI — data:image/png;base64,...
  • CSS — background: url('data:...')
  • HTML img — <img src="data:...">
  • HTML picture — responsive picture tag
  • Markdown — ![alt](data:...)

How to use?

  1. Drop, paste, or click to choose an image
  2. Adjust format, quality, or resize options
  3. Pick a copy format (Raw, CSS, HTML, etc.)
  4. Click ⧉ Copy or download
  5. Paste anywhere — HTML, CSS, JSON, API

Tips

  • Best for small images (icons, logos) under 10 KB
  • Base64 is ~33% larger than the original
  • Compress or resize before converting
  • Use WebP for smallest size
