📖 About This Tool

What is it?

Diff Checker compares two pieces of text or code and shows exactly what changed, added, or removed.

Why use it?

  • Git workflow — see changes before committing
  • Code review — compare two versions
  • API responses — find what changed between calls
  • Config files — compare .env or config.json
  • Translations — match two language files

Three View Modes

  • Side by Side — two columns, easy to scan
  • Unified — one column, Git-style
  • Inline — side by side with inline word highlighting

Options

  • Ignore case — treat A and a as same
  • Ignore whitespace — ignore spaces and tabs
  • Ignore blank lines — skip empty lines
  • Line numbers — show line numbers
  • Highlight words — highlight changed words

How to use?

  1. Paste original text on the left
  2. Paste changed text on the right
  3. Or drop files into the panels
  4. Adjust options if needed
  5. Click 🔍 Compare
  6. Copy or download the result

Tips

  • Use Swap to reverse left and right
  • Use Unified view to see Git-style output
  • Download .patch to apply in Git
  • Works with any text — code, docs, config
