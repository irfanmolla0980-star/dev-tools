📖 About This Tool

What is it?

Case Converter transforms text into 12+ different case styles used in programming, APIs, and databases.

Case Types

  • UPPERCASE — all capital letters
  • lowercase — all small letters
  • Title Case — Every Word Capitalized
  • Sentence case — First letter capital
  • camelCase — firstWordSmall, restCapital
  • PascalCase — EveryWordCapital
  • snake_case — words_with_underscores
  • kebab-case — words-with-hyphens
  • CONSTANT_CASE — ALL_CAPS_WITH_UNDERSCORES
  • dot.case — words.with.dots
  • path/case — words/with/slashes
  • aLtErNaTiNg — alternating caps

Where is it used?

  • camelCase — JavaScript variables, JSON keys
  • PascalCase — React components, classes
  • snake_case — Python variables, database columns
  • kebab-case — CSS classes, URL slugs, file names
  • CONSTANT_CASE — constants, environment variables
  • UPPERCASE — acronyms, constants

How to use?

  1. Type or paste text in the input box
  2. See all 12 case styles instantly
  3. Click any card to copy that case
  4. Adjust options if needed
  5. Click Copy All or download

Tips

  • Use camelCase for JS variables
  • Use snake_case for Python and databases
  • Use kebab-case for CSS and URLs
  • Use CONSTANT_CASE for constants
