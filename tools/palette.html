📖 About This Tool

What is a Color Palette?

A color palette is a set of colors that work well together. Developers and designers use palettes to keep a website or app visually consistent.

Why do developers need it?

  • Consistency — same colors everywhere
  • Tailwind / design systems — need 50–950 scales
  • Accessibility — must pass WCAG contrast
  • Speed — no manual color picking
  • Export ready — copy-paste into your code

What is a Shade Scale?

A shade scale is one base color broken into 11 steps from lightest (50) to darkest (950). Tailwind CSS and most design systems use this exact pattern.

Example: blue-500 is the base, blue-100 is very light, blue-900 is very dark.

What is Color Harmony?

  • Complementary — opposite on the color wheel (180°)
  • Analogous — neighbors (±30°)
  • Triadic — three evenly spaced (120°)
  • Monochromatic — same hue, different lightness

What is WCAG Contrast?

WCAG (Web Content Accessibility Guidelines) defines minimum contrast between text and background so everyone can read it.

  • AA — ratio ≥ 4.5 (normal text)
  • AAA — ratio ≥ 7 (normal text)
  • AA Large — ratio ≥ 3 (18pt+ text)

Where is it used?

  • Tailwind, Bootstrap, Material UI — all use shade scales
  • Figma, Adobe XD — design tokens
  • Any website — CSS variables for theming
  • Dark mode / light mode — needs both light & dark shades

Pro tip

Always test your palette in both light and dark mode. A color that looks great on white might fail on black. Use the Contrast Checker above before shipping.
