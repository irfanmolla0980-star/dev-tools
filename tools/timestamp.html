📖 About This Tool

What is it?

Timestamp Converter changes between Unix timestamp (a big number like 1700000000) and a human-readable date — and back.

What is a Unix Timestamp?

A Unix timestamp is the number of seconds that have passed since January 1, 1970, 00:00:00 UTC. It is used everywhere in programming.

  • Seconds: 10 digits (e.g. 1700000000)
  • Milliseconds: 13 digits (e.g. 1700000000000)

How does it work?

The tool converts the number to a date using your device's clock and timezone. It also works in reverse — a date is converted to its timestamp.

How to use?

  1. Choose mode — Timestamp → Date or Date → Timestamp
  2. Type a timestamp or a date string
  3. Output appears instantly in multiple formats
  4. Click ⧉ to copy any value
  5. Use ⬇ Use Now to fill the current timestamp
  6. Click Details for the full breakdown

Examples

  • 0 → Jan 1, 1970
  • 1700000000 → Nov 14, 2023
  • 2000-01-01 → 946684800

Tips

  • Seconds have 10 digits, milliseconds 13
  • Timestamps are always in UTC
  • Web APIs use milliseconds (JavaScript)
  • Databases often use seconds (Unix)
