📖 About This Tool

What is it?

HMAC Generator creates a Hash-based Message Authentication Code from a message and a secret key.

What is HMAC?

HMAC is a type of message authentication code. It combines a hash function (like SHA-256) with a secret key to produce a signature.

HMAC = Hash(Key + Message)

HMAC vs Hash

  • Hash — anyone can compute it
  • HMAC — needs a secret key
  • Hash — verifies data integrity
  • HMAC — verifies integrity + authenticity

Where is it used?

  • API Signing — sign API requests
  • Webhooks — verify GitHub, Stripe, Razorpay
  • JWT (HS256) — sign JSON Web Tokens
  • AWS Signature v4 — AWS API calls
  • Payment Gateways — Razorpay, PayPal
  • OAuth 1.0 — signature verification

How to use?

  1. Enter your message
  2. Enter your secret key
  3. Pick an algorithm (SHA-256 recommended)
  4. Choose output format (Hex, Base64)
  5. HMAC appears instantly
  6. Optionally paste an expected HMAC to verify

⚠️ Security

  • Never share your secret key
  • Use SHA-256 or higher
  • HMAC is not encryption — it's a signature
  • Everything runs in your browser — nothing is uploaded
