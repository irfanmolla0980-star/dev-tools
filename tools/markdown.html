📖 About This Tool

What is it?

Markdown Preview lets you write Markdown and see the rendered HTML in real time. Copy the HTML or download the file.

What is Markdown?

Markdown is a lightweight markup language for writing formatted text. Used everywhere — GitHub READMEs, blogs, documentation, notes.

All Features

  • Live Preview — real-time rendering
  • Split View — Editor + Preview, or fullscreen either
  • Toolbar — H1–H6, bold, italic, code, link, lists
  • Auto-Save — saved in your browser
  • Scroll Sync — both panels scroll together
  • Import .md — load existing Markdown files
  • Find & Replace — search and swap text
  • Emoji Picker — insert emojis quickly
  • Dark / Light theme
  • Font size — adjust editor text size
  • Print / PDF — via browser print
  • Copy Rich Text — paste into Word with formatting
  • TOC — outline of all headings
  • Download — .md or .html

Markdown Syntax

  • # H1 to ###### H6
  • **bold**, *italic*, ~~strike~~
  • `code` and ```block```
  • [link](url), ![img](url)
  • - item, 1. item
  • > quote, --- hr
  • | a | b | table
  • - [ ] task

How to use?

  1. Type or paste Markdown in the editor
  2. See the live preview on the right
  3. Use the toolbar for quick formatting
  4. Open ⚙️ More Options for extras
  5. Click Copy HTML or download

Tips

  • Use more # for smaller headings
  • Leave a blank line between paragraphs
  • Use ```language for code blocks with highlighting
  • Perfect for writing GitHub README files
