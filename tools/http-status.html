📖 About This Tool

What is it?

HTTP Status Codes are standard response codes returned by web servers to indicate the result of a request.

Categories

  • 1xx — Informational: Request received, continuing process
  • 2xx — Success: Request was successful
  • 3xx — Redirection: Further action needed
  • 4xx — Client Error: Problem with the request
  • 5xx — Server Error: Problem on the server side

Common Codes

  • 200 OK — Everything worked
  • 201 Created — New resource created
  • 301 Moved Permanently — URL changed forever
  • 400 Bad Request — Invalid input
  • 401 Unauthorized — Login required
  • 403 Forbidden — No permission
  • 404 Not Found — Resource missing
  • 500 Internal Server Error — Server crashed
  • 503 Service Unavailable — Server overloaded

Where is it used?

  • API development and testing
  • Debugging HTTP requests
  • Writing server responses
  • Reading server logs
  • Documentation

How to use?

  1. Search by code number or name
  2. Filter by category
  3. Click any card to copy the code
  4. Read details about each code

Tips

  • 200 = OK, 404 = Not Found, 500 = Server Error
  • 4xx means the client is wrong
  • 5xx means the server is wrong
  • Use 201 for successful POST requests
  • Use 401 for missing auth, 403 for wrong permission
