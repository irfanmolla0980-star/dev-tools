📖 How to Use This Tool

1

Fill the form

Enter your name, tagline, bio, and social links on the left. Everything is optional — fill what you want to show.

2

Select your tech stack

Click the skill chips to add them. Logos and badges will be auto-generated from official sources (Shields.io).

3

Choose stats cards

Toggle GitHub Stats, Top Languages, Streak, Trophies, and Visitor Counter as per your preference.

4

Watch the live preview

As you type, the live preview on the right updates instantly. See exactly how your README will look on GitHub.

5

Copy or download the README

Click Copy to copy the Markdown, or Save to download it as README.md.

6

Create a special repository on GitHub

Go to GitHub and create a new repository with the exact same name as your username (e.g. johndoe/johndoe). Check "Add a README file". This is the special repo GitHub uses for your profile README.

7

Paste and commit

Open the README.md file in that repo, click the ✏️ Edit button, delete the default content, paste your generated README, then scroll down and click Commit changes. Refresh your profile — done! 🎉

📖 About This Tool

What is a GitHub Profile README?

A GitHub Profile README is a special Markdown file that appears at the top of your GitHub profile. It's your developer "business card" — a chance to introduce yourself, showcase your skills, and link to your work.

Why do developers need it?

  • First impression — recruiters and collaborators see it first
  • Showcase skills — badges and stats highlight your stack
  • Stand out — a polished profile looks professional
  • Easy to share — one link shows your entire developer identity

How does this tool work?

You fill in the form on the left. As you type, this tool generates the Markdown code and renders a live preview instantly. Everything runs in your browser — no data is uploaded anywhere.

At the end, you copy the Markdown or download it as README.md. Paste it into your GitHub profile repository and you're done.

How to add it to GitHub (quick recap)

  1. Create a new repository with the exact same name as your GitHub username
  2. Check "Add a README file"
  3. Edit the README file and paste your generated content
  4. Commit the changes — it will appear on your profile immediately

Powered by

  • Shields.io — for tech stack badges and logos
  • GitHub Readme Stats — for stats cards
  • Streak Stats — for contribution streaks
  • GitHub Profile Trophy — for trophies
  • Komarev Visitor Badge — for visitor counter

Pro tip

Start simple. Add your name, tagline, and a few skills. Then iterate — add stats, links, and extras as you go. A clean, minimal README often works better than a cluttered one.
