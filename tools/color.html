Color Converter

Convert colors between HEX, RGB, and HSL instantly.

Pick a color or type a value below.

📖 About This Tool

What is it?

Color Converter is a tool that converts a color between three common formats — HEX, RGB, and HSL — instantly.

What are these formats?

  • HEX: A 6-digit code starting with # — like #FF0000 (red)
  • RGB: Red, Green, Blue — each from 0 to 255 — like rgb(255, 0, 0)
  • HSL: Hue (0–360°), Saturation (0–100%), Lightness (0–100%) — like hsl(0, 100%, 50%)

How does it work?

Each format describes the same color in a different way. The tool reads the value you type, figures out the color, and shows it in the other formats.

  • #FF0000 = rgb(255, 0, 0) = hsl(0, 100%, 50%)
  • #00FF00 = rgb(0, 255, 0) = hsl(120, 100%, 50%)
  • #0000FF = rgb(0, 0, 255) = hsl(240, 100%, 50%)

How to use?

  1. Click the color preview to pick a color from the palette
  2. Or type a HEX / RGB / HSL value in any field
  3. All three formats update instantly
  4. Click any Copy chip to copy that format
  5. Click Details to see the breakdown

Examples

  • #FFFFFF → rgb(255, 255, 255) → hsl(0, 0%, 100%) — white
  • #000000 → rgb(0, 0, 0) → hsl(0, 0%, 0%) — black
  • #FF5733 → rgb(255, 87, 51) → hsl(11, 100%, 60%) — orange-red

Tips

  • HEX always starts with # and uses 6 characters
  • RGB values are from 0 to 255
  • Hue in HSL goes from 0 to 360 (a full circle)
  • HEX and RGB are the most common in code
