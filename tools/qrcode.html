📖 About This Tool

What is it?

QR Code Generator creates scannable QR codes for 16 different types of data — text, URL, email, phone, SMS, Wi-Fi, vCard, location, UPI, image, event, WhatsApp, YouTube, Spotify, crypto, and PDF links.

QR Types

  • 📝 Text — plain text or note
  • 🔗 URL — website or link
  • 📧 Email — pre-filled email
  • 📞 Phone — dial a number
  • 💬 SMS — pre-filled message
  • 📶 Wi-Fi — auto-connect to Wi-Fi
  • 👤 vCard — digital contact card (12 fields)
  • 📍 Location — map coordinates + label
  • 💳 UPI — payment link (India)
  • 🖼️ Image — small image inside QR
  • 📅 Event — calendar event
  • 💬 WhatsApp — chat or message
  • 📹 YouTube — video link
  • 🎵 Spotify — track or playlist
  • ₿ Crypto — wallet address
  • 📄 PDF / Link — file or document

Error Correction Levels

  • L (Low) — 7% damage recoverable
  • M (Medium) — 15% — recommended
  • Q (Quartile) — 25%
  • H (High) — 30% — best for images

How to use?

  1. Pick a type (Text, URL, Wi-Fi, etc.)
  2. Fill in the fields
  3. Adjust size, colors, error level if needed
  4. Click ⚡ Generate QR
  5. Download as PNG, JPG, JPEG, WebP, SVG, or .txt

Download Formats

  • PNG — lossless, transparent
  • JPG — smaller, no transparency
  • JPEG — same as JPG
  • WebP — modern, small
  • SVG — vector, scales infinitely
  • .txt — just the encoded data

Tips

  • Test the QR with your phone before sharing
  • Use H error level if you add an image
  • Keep dark foreground and light background
  • Wi-Fi QR is great for cafes and offices
  • QR codes can hold ~2KB of data max
