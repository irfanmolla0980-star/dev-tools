📖 About This Tool

What is it?

Password Generator creates strong, random passwords, passphrases, and PINs. Everything runs in your browser — nothing is sent to any server.

Three Modes

  • Random: Letters, numbers, and symbols — most secure
  • Passphrase: Random words joined together — easy to remember
  • PIN: Only digits — for ATMs, phones, locks

Quick Presets

  • 📧 Email — 16 chars, easy to type
  • 🌐 Website — 20 chars, strong
  • 📱 Wi-Fi — 24 chars, symbols included
  • 🏦 Banking — 32 chars, maximum security
  • 🎮 Gaming — 12 chars, simple
  • 🔐 Maximum — 64 chars, all types
  • 📌 PIN — 6-digit number
  • 💬 Passphrase — 4 words

Strength Meter

Uses entropy (bits of randomness) to measure strength:

  • Weak: Under 40 bits
  • Fair: 40–60 bits
  • Good: 60–80 bits
  • Strong: 80–100 bits
  • Very Strong: 100+ bits

How to use?

  1. Pick a preset (for quick use) — or
  2. Choose a mode and customize options
  3. Set quantity (1–25)
  4. Click 🔑 Generate Password
  5. Copy each password with the ⧉ button
  6. Click Details to see entropy and crack time

Tips

  • Use 16+ chars for important accounts
  • Never reuse passwords across sites
  • Passphrases are easier to remember and very strong
  • Store passwords in a password manager
  • This tool works offline — nothing is uploaded
