📖 About This Tool

What is it?

JWT Decoder splits a JSON Web Token into its three parts — Header, Payload, and Signature — and shows them in readable format.

What is JWT?

A JWT is a compact token used for authentication. It has three parts separated by dots:

  • Header — algorithm and type
  • Payload — data (user ID, name, expiry)
  • Signature — used to verify authenticity

Standard Claims

  • iss — Issuer (who made it)
  • sub — Subject (who it's for)
  • aud — Audience (who can use it)
  • exp — Expiration time
  • nbf — Not Before
  • iat — Issued At
  • jti — JWT ID (unique)

Where is it used?

  • Login and authentication systems
  • REST API authorization
  • Single Sign-On (SSO)
  • Mobile app authentication
  • Microservices communication

How to use?

  1. Paste your JWT in the input box
  2. Click Decode (or it auto-decodes)
  3. See Header, Payload, Signature
  4. Check expiry status
  5. Copy any part you need

⚠️ Important

  • JWT is NOT encrypted — anyone can decode it
  • Never put secrets (passwords, keys) in a JWT payload
  • Signature verification needs the secret key (server-side)
  • This tool only decodes, it does not verify
